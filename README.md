# Catálogo personal · cuatro sitios web

Cuatro sitios independientes, cada uno con su propia portada, aplicación PWA, estilos, scripts, manifiesto, icono y Service Worker.

## Sitios
- **Navaja 27** — en la raíz del repositorio.
- **The Gentleman's Club** — `/the-gentlemans-club/`.
- **El Local · Antojitos** — `/antojitos/`.
- **Gráficas PC** — `/graficas/`.

El sitio de Antojitos usa el menú y las imágenes proporcionadas para las 19 opciones. El catálogo de gráficas es referencial; confirmar precio y stock con la tienda.

## Publicar con GitHub Pages
En Settings → Pages, seleccionar **Deploy from a branch**, rama **main** y carpeta **/(root)**. Guardar. La portada se publica en la raíz y los otros sitios quedan disponibles en sus respectivas rutas.

Este repositorio no contiene la página personal, el Cibercafé, la veterinaria ni carpetas de ejercicios.
